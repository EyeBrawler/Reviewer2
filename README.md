# Reviewer2
A Blazor Web Application for Managing an Academic Conference

To learn how to deploy Reviewer2, view `Deployment/README.md`


After deployment...

1. Enter the username `admin@reviewer2`

2. Push "Forgot your password?"

3. Change the password for the admin user.

4. Login as admin and create additional users. From the admin user, the Admin Panel can be used to delegate roles.
